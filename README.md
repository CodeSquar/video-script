# video-script

Scripts for short videos that people watch to the end.

TikTok, Reels, Shorts. As short as the idea allows.

## Why

Ask an agent for a script and you get the same one every time: "Did you know…?", three benefits, "The result? Insane.", a moral at the end. Viewers spot it in a second and swipe. This skill fixes that:

- **Payoff first.** One idea per video. Write what the viewer gets, then the hook that promises it.
- **A hook that is one specific spoken line.**
- **Something new every line.** Open loops, a re-hook where retention sags, cut right after the payoff.
- **Sounds like a person.** AI structures and words banned by name, in English and Spanish.
- **Real things only.** No invented stats. A missing fact stays marked for you to fill in.

## Install

```
npx skills add CodeSquar/video-script
```

## Use

```
/video-script
```

Give a topic. Get the spoken lines, three alternative hooks and a caption.

Pairs with [video-edit](https://github.com/CodeSquar/video-edit): the spoken lines become the video's voice-over.
